## Premier arrivé, premier servi
L'inscription à une mission est immédiate et sans validation. Il n'y a pas de sélection : le premier bénévole à s'inscrire obtient la place. Si une place est libre, vous êtes confirmé(e) tout de suite.

## Liste d'attente
Si la mission est complète, vous rejoignez la liste d'attente. L'ordre est celui d'arrivée : votre rang est visible dans votre espace personnel. Si un inscrit annule, le premier de la liste est automatiquement confirmé et prévenu par e-mail.

## Certificats et vérification par code
Après la mission, l'association délivre un certificat PDF avec un code unique. Ce code est vérifiable publiquement sur countmein.ma/certificat, sans avoir besoin d'un compte.

## Créer un compte
Cliquez sur « Devenir bénévole » ou « Je suis une association » en haut de la page d'accueil, puis remplissez le formulaire d'inscription.
